# Thread Ceremony Invitation

Open `index.html` in a modern browser. The design is a single self-contained webpage; it does not need a build step or a server. Google Fonts are used when an internet connection is available, with system font fallbacks offline.

## Personalize

1. Open **Edit this invitation** at the lower right.
2. Click any highlighted text and replace it directly.
3. Set the event date and time, venue, and RSVP deadline in the editor panel.
4. Choose **Save changes**. Text and settings are saved in that browser on that device.

The RSVP form records replies in that browser's local storage only. To collect guest replies from other devices, connect the form to an RSVP service or backend. The calendar button downloads an `.ics` file using the selected event details. The map link searches Google Maps for the venue entered in the editor.

Use **Reset** in the editor panel to restore the sample invitation. This also resets the local RSVP records only if you clear the browser's local storage for this page; RSVP records are separate from the invitation copy.
